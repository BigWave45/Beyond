# BEYOND

**An interactive universe for exploring the strange, the beautiful and the not-yet-understood.**

BEYOND brings art, science, mathematics, philosophy and creative experiments into one expandable digital space.

## Current build

The first milestone establishes the responsive homepage and six-world navigation:

- Infinity
- Dimensions
- Perception
- Patterns
- Consciousness
- Art

Each world currently opens an introductory panel. Interactive experiments are being developed as independent modules.

## Stack

- React + TypeScript
- Vite
- CSS
- Lucide icons
- Canvas/WebGL experiments planned for subsequent milestones

## Run locally

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
```

## Design principles

- Mobile-first, with desktop layouts supported
- Immersive dark visual system with editorial typography
- Artwork is part of the experience, not decoration
- Scientific, philosophical and spiritual claims are distinguished
- Each world is designed to expand independently

## Status

Early development. The homepage and world introduction panels are the first implementation milestone; full interactive experiments are not yet complete.


Cloudflare Pages preview integration is configured for this repository.
